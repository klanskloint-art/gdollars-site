## Как работать (обязательно)
1. Код — vanilla JS SPA без сборки: `index.html` + `config.js` + `assets/*.js|css` + `data/*.js`. Роутинг по `location.hash`.
2. После любой правки **подними версию** `?v=N` у всех `<script>/<link>` в `index.html` (на 21.10.2026 — `v=185`), иначе браузеры держат кеш.
3. Проверка синтаксиса: `node -e "new Function(require('fs').readFileSync('assets/app.js','utf8'))"`. Визуальная проверка — Playwright (см. `docs/memory/03-workflow.md`).
4. Публикация = `git commit` + `git push origin main` → GitHub Pages обновляется сам за 1–2 мин. Netlify больше НЕ используется (кончились кредиты).
5. Отвечай пользователю по-русски, пошагово, нумерованными шагами «куда нажать». Он не программист.

## Жёсткие правила (не нарушать)
- Не копировать фото/данные с сайтов конкурентов (Pont и др.), не скрапить Poizon/Farfetch и т.п. в обход защиты, не делать «бесплатную копию Poparce».
- Не помогать заводить несколько аккаунтов Poparce ради бесплатных запросов (пользователь просил — отказано).
- Не подделывать статусы заказов/оплату, не делать фейковые отзывы/скидки/баллы.
- Секреты: токен бота Telegram (часть после `:`) никогда не в коде/чате. Публичные ключи (logo.dev `pk_`, Brandfetch client id, Poparce key — по решению владельца) лежат в `config.js`, репо публичный.
- Не добавлять в репо личные данные владельца сверх того, что уже есть в `config.js`.
