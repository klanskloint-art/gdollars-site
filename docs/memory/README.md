# Память проекта G&Dllars

Файлы для продолжения работы после очистки контекста или в новой сессии/аккаунте.

1. `01-project.md` — ссылки, аккаунты, сервисы, бизнес-правила цен.
2. `02-architecture.md` — устройство кода, файлы, функции, маршруты.
3. `03-workflow.md` — как править, проверять, публиковать; Cloudflare Worker.
4. `04-integrations.md` — Poparce API, Worker, логотипы, Telegram.
5. `05-rules-and-decisions.md` — запреты и решения владельца.
6. `06-user-preferences.md` — как общаться с владельцем.
7. `07-status-and-todo.md` — где остановились, открытые задачи. **Обновлять после каждой сессии.**
8. `08-texts.md` — готовые письма (Poizon, Poparce).

Резервные копии: вся история в git (каждый коммит = снимок сайта). Метки `backup-YYYY-MM-DD` — стабильные точки. Откат: `git checkout backup-2026-10-21 -- .` (или `git revert <commit>`).
