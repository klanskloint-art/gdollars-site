# 05. Правила и принятые решения

## Отказы (повторно просили — держать позицию, вежливо, коротко, с альтернативой)
- Копировать фото/товары/цены с Pont.uz, Farfetch, открытых аккаунтов, Poizon «по-серому» — нет. Альтернативы: свои фото, Poparce, официальное партнёрство с Poizon, платные базы с лицензией.
- Писать «бесплатную версию/копию Poparce» (доступ к закрытому API Poizon в обход защиты) — нет.
- Несколько аккаунтов/номеров ради бесплатных запросов Poparce, объяснять «как не заметят» — нет.
- Автоматически переводить заказ в «Оплачено/Доставлено» без реальной оплаты — нет (статусы двигает владелец кнопками).
- Фейковые отзывы, «баллы», фейковые скидки 50% — нет.
- Рисовать официальные логотипы брендов вручную — нет (только через logo.dev/Brandfetch).

## Решения владельца
- Токен Poparce держим прямо в `config.js` (публичный репо) — «пусть тратят». Предупреждён.
- Хостинг: GitHub Pages (бесплатно), Netlify брошен.
- Наценки по категориям (см. 01-project.md), курс 1750.
- `onlyReal: false` — «нарисованные» товары снова показаны (владелец сначала попросил убрать, потом вернуть). Когда придёт `poizon-catalog.js` с 500 настоящими товарами — договорились выложить и **убрать нарисованные** (`onlyReal: true`).
- Баннер бренда: цветной (`BRAND_COLORS`), вариант «логотип по центру с растянутыми краями» откатан.
- Главный слайдер: 2 плашки «Совсем ...» (ярко-розовая) и «Скоро...» (ярко-голубая), смена 10 с, плавная полоска.
- Дизайн равняется на Pont.uz (шапка, бренды, каталог, поиск) — но только расположение/стиль, не их контент.

## Честность в интерфейсе
- Шаблонные товары (`est: true`) показывают пометку «наличие расцветки и точную цену подтвердит оператор до оплаты».
- Правило цен по размерам `sizeFactor` — моя прикидка (не данные Poizon). Владелец спросил «ты сам придумал?» — да; предложено убрать, ответа нет. Владелец хочет **настоящие** цены по размерам с Poizon → нужна квота Shihuo в Poparce.
