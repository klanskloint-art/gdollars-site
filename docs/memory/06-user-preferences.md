# 06. Как общаться с владельцем

- Язык: русский, просто, без терминов. Он не программист.
- Формат: короткие пронумерованные шаги «куда нажать», жирным — названия кнопок. Один шаг = одно действие. Если он присылает скриншот и пишет «куда/дальше» — смотри скрин и называй конкретную кнопку на нём.
- Часто работает с телефона; иногда с компьютера (Chrome, Windows). Вставка в веб-редакторы — только Ctrl+V (правая кнопка мыши не работает в Cloudflare).
- Любит «точно как у Pont» — присылает скриншоты Pont для образца (расположение, размеры, цвета).
- Нетерпелив к длинным объяснениям; при отказах объясняй коротко и сразу давай законную альтернативу.
- Иногда ругается — отвечай спокойно, без извинений-простыней.
- После каждого изменения говори: «обнови страницу Ctrl+Shift+R» и что именно поменялось.
- Не присылать ему длинные куски кода без необходимости; если код надо вставить (Cloudflare) — один блок целиком + «Ctrl+A → Delete → Ctrl+V → Deploy».
- Скриншоты сайта после правок полезны (SendUserFile), но в песочнице нет интернета — на них GD-заглушки вместо логотипов/фото, предупреждай.
